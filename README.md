# Titanic Survival EDA

A comprehensive exploratory data analysis (EDA) of the Titanic dataset, investigating patterns and factors that influenced passenger survival rates.

## Overview

This project performs an in-depth exploratory data analysis of the famous Titanic dataset. Through statistical analysis and data visualization, we uncover insights about passenger demographics, ticket information, and survival outcomes.

## Dataset

The dataset contains information about passengers aboard the RMS Titanic, including:
- **Passenger demographics**: Age, gender, class
- **Ticket information**: Fare, cabin, port of embarkation
- **Survival status**: Whether the passenger survived the sinking

## Project Structure

This repository contains Jupyter notebooks that walk through the analysis process:

- Data loading and initial exploration
- Data cleaning and preprocessing
- Univariate analysis (individual variable distributions)
- Bivariate analysis (relationships between variables)
- Multivariate analysis (complex relationships)
- Key insights and conclusions

## Key Findings

Through this EDA, we examine:
- How gender, age, and passenger class affected survival rates
- The relationship between ticket fare and survival
- Family size and group dynamics among passengers
- Geographic patterns (port of embarkation)
- Missing data patterns and their implications

## Technologies Used

- **Python**: Data analysis and visualization
- **Jupyter Notebook**: Interactive analysis environment
- **Pandas**: Data manipulation and analysis
- **Matplotlib & Seaborn**: Data visualization
- **NumPy**: Numerical computations

## Getting Started

### Prerequisites
- Python 3.7+
- Jupyter Notebook
- pandas
- matplotlib
- seaborn
- numpy

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yashasgaur/Titanic-Survival-EDA.git
cd Titanic-Survival-EDA
```

2. Install required packages:
```bash
pip install pandas matplotlib seaborn numpy jupyter
```

3. Launch Jupyter Notebook:
```bash
jupyter notebook
```

## Usage

Open the Jupyter notebooks in the repository to explore the analysis step by step. Each notebook is self-contained and includes:
- Clear explanations of each analysis step
- Visualizations to illustrate findings
- Code comments for reproducibility
